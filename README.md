# CampusArc AI

Global, mobile-first education + AI + USDC campus platform built around the Arc ecosystem.

## Development status

Active development. Production readiness is not claimed until the project passes the QA Release Gate.

## Safety rules

- Never commit secrets, API keys, private keys, seed phrases, or real environment values.
- Vercel deployments are intentionally deferred until build/config validation is complete.
- Blockchain payment status is only considered complete after actual verification and reconciliation.
